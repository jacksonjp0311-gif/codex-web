# codex/history

Historical and archival runtime material for Codex.

## Purpose

This area groups legacy modules and historical artifacts that are retained for continuity, reproducibility, and reference—not as the primary active runtime path.

## Contents

- `ancient/` — older engines and historical module families.
- `archive/` — archived runtime outputs/material.
- `system_dumps/` — large diagnostic/full-dump artifacts.

## Usage guidance

- Treat these paths as read-mostly.
- Avoid writing new active runtime outputs here.
- Prefer adding migration notes if active modules depend on historical content.
